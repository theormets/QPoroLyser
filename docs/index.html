About QPoroLyser

QPoroLyser is an AI-based tool developed for automated quantitative analysis of porosity in microstructures. The system detects, segments and classifies pores according to their morphology and generates a class-resolved porosity fingerprint.

The tool was developed using microstructural images of high-frequency-induction-sintered commercially pure titanium and is designed to provide an accessible workflow for quantitative porosity analysis.

Key Features

Automated Detection

Automatically detects pores from metallographic micrographs using deep learning.

Segmentation

Provides quantitative pore regions for detailed microstructural analysis.

Morphology Classification

Classifies pores into spherical, irregular and network morphologies.

Porosity Fingerprint

Generates class-resolved pore count and pore area information for quantitative comparison.

Accessible Workflow

Browser-based application requiring no local installation or programming expertise.

Open Dataset

Includes access to a large database containing more than 370,000 individually cropped porosity instances.
